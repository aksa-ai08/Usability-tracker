# T20 World Cup 2021 – Ultimate Experience

An interactive and visually engaging website dedicated to the T20 World Cup 2021. The project presents tournament information, participating teams, featured matches, star players, records, and an interactive Usability Tracker to analyze user engagement.

# Features
Interactive Home Page
Tournament Overview
Participating Teams
Team Like/Preference System
Team Preference Pie Chart
Featured Matches
Star Players and Tournament Stats
Tournament Records
Real-Time Click Tracking
Interactive Click Heatmap
Session Duration Tracking
Page View Tracking
User Activity Log
Usability Score
Reset Tracker Function
Interactive Confetti Effects
Responsive Design

# Technologies Used
HTML5
CSS3
JavaScript
HTML5 Canvas
Canvas Confetti Library

# Usability Tracker

The project includes an interactive usability analytics system that tracks:

Total page views
Total user clicks
Session duration
Bounce rate
Most-clicked element
Team preferences
User activity
Click density through a heatmap
Overall usability score
