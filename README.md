# Usability Tracker 

A web-based Usability Tracker designed to evaluate and analyze user interaction with a website. The **T20 World Cup 2021 website is used as the System Under Test (SUT)** for collecting and analyzing usability data.

# Features

* Website Interaction Tracking
* Page View Tracking
* Total Click Tracking
* Session Duration Tracking
* User Activity Monitoring
* Bounce Rate Tracking
* Most-Clicked Element Detection
* Click Heatmap
* Team Preference Tracking
* Team Preference Pie Chart
* Usability Score
* Activity Log
* Reset Tracker Function
* Interactive Data Visualization
* Responsive Design

# System Under Test (SUT)

The T20 World Cup 2021 website is used as the test website for the Usability Tracker. It includes:

* Interactive Home Page
* Tournament Overview
* Participating Teams
* Team Like/Preference System
* Featured Matches
* Star Players and Tournament Statistics
* Tournament Records
* Interactive UI Elements

User interactions with these features are monitored by the Usability Tracker to evaluate website usability and engagement.

# Usability Tracker

The tracker collects and analyzes:

* Total Page Views
* Total User Clicks
* Session Duration
* Bounce Rate
* Most-Clicked Element
* User Activity
* Team Preferences
* Click Density through Heatmap
* Overall Usability Score

The collected data helps identify user interaction patterns and provides insights into the usability of the tested website.
